Documentation: Scene 5

Scene 5 has two scenes: a garden where you collect orbs, and a night arena you reach after collecting all five (or by pressing the GUI button). Code: js/scene5.js.

Concept and design

The game is basically about collecting orbs in two different places. You control this glowing ball and need to get five of them. Once you have all five it switches you over to the other area which is darker and stuff. But you can also just switch back and forth whenever you want using a button.

Both places follow the same collecting rules. The first one looks bright with a light sky and green ground and the orbs are pink. The second is like a night arena with dark sky and blue grey ground and cyan orbs plus this light that moves with you.

Everything is made in code without any outside files. Meshes come from MeshBuilder and textures are drawn right there and sounds too with web audio. That way no license problems and the whole thing stays small even if it looks basic.

Code structure

make(night) builds one scene (camera, light, ground, player, orbs, GUI, update logic). It is called twice, so both scenes share the same code with different settings. common.js holds helpers used by all scenes.

const A = make(false), N = make(true); active = A;
function swap() { active = (active === A ? N : A); }
return { render: () => active.render() };

Scene event and GUI update

Each frame, the distance between player and orbs is checked. A close orb is disposed, the GUI text changes, a sound plays, and after 5 orbs the scene switches.

if (B.Vector3.Distance(o.position, pl.position) < 1.2) {
  o.dispose(); score++; lab.text = 'Orbs: ' + score + ' / 5'; beep(660);
  if (score >= 5) { score = 0; swap(); }
}

GUI, transitions and audio

Each scene has its own gui setup with the label and buttons. Sound only starts after a click because of how browsers work.

Evaluation

The main parts worked out like having the two scenes and the gui that changes with the orbs collected. Audio starts off and you turn it on with the button. Switching works both ways too. Keeping files separate helped a lot with keeping things organized.

One issue came up where the gui parts did not show up at first. It turned out the library was not loading properly from the first cdn. Switching to the official one fixed it and I added an error message just in case.

There are some limits though. The score is the same in both but each has its own orbs so switching can mess that up. Collisions are just distance checks. If there was more time it would be good to add more stuff like enemies or a timer. Also maybe keep scores separate per scene.
